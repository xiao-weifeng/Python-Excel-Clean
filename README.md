### 项目介绍

本项目为**业务台账自动化清洗与关联汇总流水线**，面向中小商贸、电商客户，解决多来源分散 Excel 台账难以统一汇总、脏数据多、重复数据难排查、人工汇总效率低的问题。
很多企业的销售台账分散在多人手里，每份表格格式不统一，数量、价格单元格混杂单位、备注文字，存在空行、重复记录、格式混乱等问题，人工整理耗时且容易出错。本脚本实现全流程自动化处理。

### 核心功能

1. **自动批量读取 & 智能表分类**
自动扫描输入目录下全部 `.xlsx` 文件，读取所有工作表；通过表头集合匹配规则，自动区分【订单事实表、商品维度表、客户维度表】，自动归类合并同类型多张表格，无需人工指定表结构。
2. **脏数据清洗 + 异常标记机制**
使用正则表达式清洗数量、价格、商品名称字段，提取有效数值；
👉 重点设计：**异常数据不直接丢弃，增加标记字段**，同时保留【来源文件、来源 sheet、原始行号】溯源信息，业务方可以复核脏数据，规避直接删数据带来的数据风险。
3. **标准化处理**
自动剔除全空无效行；统一日期格式、ID 数值类型；基于业务主键（订单 + 商品 ID、商品 ID、客户 ID）进行去重，保留首条有效记录。
4. **多表关联（星型模型左连接）**
以订单表为主表，左连接商品表、客户表，合成一张包含订单信息、商品信息、客户信息的完整宽表，用于后续统计、报表制作。
5. **日志输出 & 高鲁棒容错**
内置 logging 日志系统，控制台 + 本地日志文件双输出，记录识别情况、清洗行数、去重数量、报错信息；加入 try-except 异常捕获，损坏文件、格式不符的工作表仅告警跳过，不会终止整个任务。
6. **低门槛复用**
输入输出路径、表头规则集中在顶部配置区，客户更换台账文件、调整识别规则，仅修改配置即可复用，不需要修改核心逻辑代码。

### 技术亮点（接单的时候重点突出，拉开和简单脚本的差距）

- 工程化思路：分离配置、工具函数、业务流程、输出模块，代码可维护，不是一次性粘贴脚本；
- 数据安全思维：溯源字段 + 异常标记，是专业数据处理和随便写脚本最大的区别，客户很看重这点；
- 遵循数仓星型模型思想：事实表 + 维度表的关联方式，可拓展对接后续统计、可视化需求；
- 兼容 Jupyter 调试，方便快速根据客户的特殊脏数据规则迭代调整清洗逻辑。
